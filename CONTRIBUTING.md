# Contributing

Contributions are welcome through focused pull requests.

1. Explain the problem and intended behavior.
2. Keep security defaults conservative.
3. Preserve human approval gates.
4. Run `bash -n bin/ai-orchestrator`.
5. Test `on`, `off`, `toggle`, `status`, and cancellation behavior without exposing secrets.
6. Document user-visible changes.

Do not add automatic push, merge, commit, deployment, destructive commands, or permission bypasses as defaults.
